Support

FAQ

Penjelasan singkat tentang cara kerja sistem MOTRA.

Apakah MOTRA benar-benar terhubung dengan motor?

Belum. MOTRA pada halaman ini menggunakan data aplikasi lokal sehingga status kendaraan dan sensor belum membaca perangkat motor secara langsung.

Apakah lokasi motor benar-benar real-time?

Tidak secara default. Malang digunakan sebagai lokasi kendaraan. Fitur lokasi browser hanya dijalankan ketika pengguna memilihnya, sedangkan informasi tempat terdekat berasal dari data lokal dan bukan data real-time.

Bagaimana alarm bekerja?

Pemeriksaan keamanan yang relevan dapat mengaktifkan banner bahaya dan mencoba memainkan alaram.mp3. Browser dapat menolak autoplay; karena itu pemicu dilakukan setelah interaksi pengguna.

Apakah data tersimpan?

Ya, beberapa preferensi, profil, kendaraan, dan histori disimpan di localStorage. Mekanisme ini bukan penyimpanan aman untuk production.

Mengapa model 3D tidak muncul?

MOTRA menampilkan pratinjau 3D Honda Beat Pop eSP langsung dari Sketchfab. Jika viewer gagal dimuat, periksa koneksi internet lalu gunakan tombol pembuka tampilan 3D.

About

Tentang MOTRA

Smart Motorcycle Security & Monitoring System.

MOTRA

MOTRA merupakan sistem pemantauan dan keamanan sepeda motor yang menggabungkan monitoring kendaraan, keamanan, lokasi, notifikasi, pemeriksaan respons, dan visualisasi kendaraan 3D dalam satu pengalaman web.

Security

Status keamanan dibuat interaktif untuk menunjukkan bagaimana sistem dapat merespons gangguan.

Monitoring

Pengamatan dan histori memperlihatkan perubahan kondisi secara kronologis.

System

Status kendaraan dan sensor pada versi ini dikelola oleh aplikasi lokal; koneksi hardware atau telemetry real-time belum digunakan.
